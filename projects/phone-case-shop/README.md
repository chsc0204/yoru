# 폰케이스 쇼핑몰 📱

카테고리 필터, 실시간 검색, 장바구니, 다크 모드까지 갖춘 **폰케이스 쇼핑몰 데모 사이트**입니다.
프레임워크나 서버 없이 순수 HTML5 / CSS3 / Vanilla JavaScript(ES6+)만으로 동작하며,
실제 결제는 연동되어 있지 않은 UI/UX 데모입니다.

포트폴리오의 "폰케이스 쇼핑몰" 프로젝트 카드 Demo로 연결되어 있습니다.

---

## 1. 실행 방법

외부 데이터를 `fetch`하지 않으므로 **로컬 서버 없이 바로 열어도 정상 동작**합니다.

1. `index.html`을 더블클릭해서 기본 브라우저로 열기
2. 또는 로컬 서버로 열기
   ```bash
   cd projects/phone-case-shop
   python -m http.server 8000
   ```
   브라우저에서 `http://localhost:8000` 접속


## 3. 주요 기능

| 영역 | 구현 내용 |
|---|---|
| 상품 목록 | 30종 상품 그리드, NEW/BEST 배지, 할인가 표시, PC 4열 · 태블릿 3열 · 모바일 2열 반응형 |
| 카테고리 필터 · 검색 | ALL/CLEAR/SILICONE/HARD/CHARACTER/ETC 필터, 실시간 검색(결과 없음 안내 포함) |
| 상품 상세 모달 | 이미지·설명·수량 선택, 장바구니 담기 / 바로 구매, X·바깥 클릭·ESC로 닫힘 |
| 장바구니 | Drawer 형태, 수량 증감·삭제, 합계 실시간 계산, `localStorage`로 새로고침 후에도 유지 |
| Checkout · 주문 완료 | 배송 정보 입력 폼 → 주문 요약 → 주문번호 발급 화면, 완료 후 장바구니 자동 비움 |
| 다크 모드 | 헤더 토글 버튼(🌙/☀️), `localStorage`에 저장되어 새로고침해도 유지 |
| Toast 알림 | 장바구니 추가/삭제 시 하단 알림, 자동 소멸 |

## 4. 기술 스택 및 설계 결정

- **프레임워크 미사용**: React/Vue 등 없이 Vanilla JS로 상태(장바구니, 테마, 필터)를 직접 관리합니다.
- **CSS 변수 기반 테마**: `--color-*` 커스텀 프로퍼티로 라이트/다크 팔레트를 분리하고,
  `:root[data-theme="dark"]`로 전환합니다.
- **영속화는 전부 `localStorage`**: 장바구니 내용, 다크 모드 여부 모두 새로고침에도 유지됩니다.
- **결제 미연동**: 실제 PG사 연동, 카드 결제, 서버 전송은 없습니다. Checkout은 입력값을 화면에
  다시 보여주는 데모이며, 주문번호는 `CASE-YYYYMMDD-XXX` 형식으로 클라이언트에서 생성합니다.

---

## 5. 알려진 제한사항 (Out of Scope)

- 실제 결제/배송 연동, 회원가입·로그인, 재고 관리 등은 포함하지 않습니다.
- 상품 이미지는 Unsplash의 무료 스톡 사진으로, 실제 판매 상품 사진이 아닙니다.
- 새로고침 시 유지되는 것은 장바구니와 테마뿐이며, 검색어/필터 상태는 유지되지 않습니다.
