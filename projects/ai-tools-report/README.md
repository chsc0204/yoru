# AI 도구 2025 하반기 인기 보고서 📊

2025년 하반기(7~12월) 가장 인기 있었던 AI 도구를 웹 트래픽, 활성 사용자 수, 개발자 설문,
기업 도입 조사 등 여러 지표를 종합해서 정리한 **리서치 리포트**입니다.

포트폴리오의 "AI 도구 2025 하반기 인기 보고서" 프로젝트 카드 Demo로 연결되어 있습니다.

---

## 1. 실행 방법

로컬 서버 없이 바로 열어도 정상 동작합니다.

1. `index.html`을 더블클릭해서 기본 브라우저로 열기
2. 또는 로컬 서버로 열기
   ```bash
   cd projects/ai-tools-report
   python -m http.server 8000
   ```
   브라우저에서 `http://localhost:8000` 접속

---

## 2. 폴더 구조

```
ai-tools-report/
├─ index.html                              # 리포트 본문 + 상단 "원본 파일 다운로드" 바 (Demo 화면)
├─ AI도구_2025하반기_인기보고서.html         # 리포트 원본 HTML (인쇄/PDF 변환용 스타일 포함)
├─ AI도구_2025하반기_인기보고서.pdf          # 리포트 PDF 버전
├─ AI도구_2025하반기_인기보고서.docx         # 리포트 Word 버전
└─ AI도구_2025하반기_인기보고서.md           # 리포트 Markdown 버전
```

`index.html`은 `AI도구_2025하반기_인기보고서.html`의 리포트 내용을 그대로 담고 있으며,
그 위에 다운로드 바만 추가한 버전입니다.

---

## 3. Demo 화면 구성

`index.html` 상단에 고정된 **"📄 원본 파일 다운로드"** 바에서 같은 폴더의 원본 파일로 바로
연결됩니다.

| 버튼 | 연결 파일 |
|---|---|
| PDF 다운로드 | `AI도구_2025하반기_인기보고서.pdf` |
| Word(.docx) 다운로드 | `AI도구_2025하반기_인기보고서.docx` |
| Markdown(.md) 다운로드 | `AI도구_2025하반기_인기보고서.md` |

다운로드 바는 인쇄(`@media print`) 시에는 자동으로 숨겨져, 리포트를 PDF로 출력해도
바가 함께 인쇄되지 않습니다.

## 4. 리포트 목차

1. 조사 개요 (대상 기간, 범위, 판단 기준)
2. 조사 방법론 (웹 트래픽 · 앱 랭킹 · 기업 도입 · 개발자 설문 · 업계 동향)
3. 종합 결과 요약
4. 카테고리별 인기 도구 (챗봇/어시스턴트, 코딩 어시스턴트, 이미지·영상 생성, 생산성 통합 도구)
5. 글로벌 웹 트래픽 순위 (Similarweb 기준)
6. 기업(엔터프라이즈) 도입 동향 (Menlo Ventures)
7. 개발자 커뮤니티 동향 (Stack Overflow 2025 Developer Survey)
8. 결론 및 시사점
9. 참고 자료(출처) 16건
