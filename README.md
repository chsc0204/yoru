# Snake Game

pygame 기반 스네이크 게임입니다.

## 실행 방법
```
python snake_game.py
```

## 조작법
- 방향키 또는 WASD: 이동
- ESC: 종료
- 게임오버 후 R: 재시작

## 기능
먹이를 먹을수록 점수가 오르고 속도가 점점 빨라집니다.

# 물체 탐지기 (index.html)

사진을 올리면 TensorFlow.js의 COCO-SSD 모델로 사람·동물 등의 물체를 인식해서
박스와 확률(%)로 표시해주는 웹페이지입니다. 순수 HTML/CSS/JavaScript로 만들어졌습니다.

## 여는 방법
1. `index.html` 파일을 더블클릭해서 기본 브라우저로 열기
2. 또는 로컬 서버로 열기
   ```
   python -m http.server 8000
   ```
   브라우저에서 `http://localhost:8000` 접속

인터넷 연결이 필요합니다 (CDN에서 TensorFlow.js와 COCO-SSD 모델을 불러옵니다).

## 사용법
1. "파일 선택"으로 사진 업로드
2. "물체 찾기" 클릭
3. 탐지된 물체마다 노란 박스와 `이름 확률%` 라벨이 표시되고,
   하단에 `물체 N개를 찾았어요: 이름1, 이름2` 형식으로 결과가 나옵니다
